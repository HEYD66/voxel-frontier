# 方境 · Voxel Frontier

一个基于 Three.js、TypeScript 和原创程序化素材制作的浏览器 3D 方块生存沙盒。

游戏包含确定性地形、洞穴、矿物、树木、水体、昼夜与云层，以及生存/创造模式、
生命和饥饿、游泳与溺水、跌落伤害、2x2/3x3 合成、熔炉、木石铁钻工具、剑与护甲耐久、
攻击蓄力、猪羊牛等动物、僵尸与苦力怕、爆炸破坏和世界掉落物。肉类可在熔炉中烹饪，沙子可烧制成玻璃。

> 本项目是独立开发的原创体素游戏，不是 Minecraft 官方产品，也不包含或分发 Mojang/Microsoft 的代码、商标、纹理或音频。

## 运行

### Windows 一键启动

1. 安装 [Node.js](https://nodejs.org/) `20.19+` 或 `22.12+`（建议使用当前 LTS 版本）。
2. 双击项目根目录的 `start-game.cmd`。

启动器会检查 Node.js 与 npm，并在依赖缺失或项目依赖清单更新时自动执行安装。随后它会在 `127.0.0.1:5173` 启动游戏并打开浏览器；如果端口已占用，Vite 会自动选择后续可用端口。回到启动器窗口按 `Ctrl+C` 即可停止服务器。

### 命令行启动

需要 Vite 7 支持的 Node.js 版本（`20.19+` 或 `22.12+`）和 npm。在项目目录执行：

```bash
npm ci
npm run dev
```

启动后打开终端中 Vite 输出的本地地址。开发服务器支持热更新；也可以按住 `Ctrl+C` 停止服务器。

测试、生产构建与本地预览：

```bash
npm test
npm run build
npm run preview
```

## 操作

- `WASD` 移动，`Space` 跳跃，`Ctrl` 冲刺，`Shift` 潜行
- 鼠标移动观察；左键攻击实体，按住左键破坏方块，右键放置方块，中键选取方块
- 手持食物时按住右键约 1.61 秒进食，提前松开、切换槽位或打开菜单会取消
- `1` 到 `9` 或滚轮切换快捷栏
- `E` 打开或关闭物品栏与合成界面，`Esc` 关闭界面、暂停或继续游戏
- 触屏设备提供虚拟摇杆、观察区、跳跃、潜行、破坏和放置按钮

## 关键机制

### 合成与配方书

- 玩家物品栏使用 2x2 合成格，工作台使用 3x3 合成格
- 点击配方书条目只会从背包取出一批材料并填入当前合成格，不会直接生成成品
- `Shift` 点击配方条目会在材料和槽位上限允许时继续增加批次
- 填好材料后仍需点击输出槽：普通点击把一份成品拿到鼠标上，`Shift` 点击批量放入背包
- 如果原合成格物品无法安全退回背包，或材料不足，配方填充不会改变背包与合成格
- 火把配方为煤炭在上、木棍在下的竖直排列，每次制作 4 个火把
- 箱子配方为 3x3 合成格中 8 个木板围绕空中心，每次制作 1 个箱子

### 箱子

- 单箱提供 27 个储物槽，支持左右键拆分/放置、`Shift` 双向转移和双击收集同类物品
- 同高度、同朝向且左右相邻的两个箱子会合并为 54 槽大箱子；三连箱、桥接两个箱子和继续连接已有大箱子的放置会被拒绝
- 箱子内容和朝向按方块坐标持久化；拆除大箱子的一半时，只掉落该半箱的 27 槽物品，另一半保留库存并恢复为单箱
- 箱体高 `14/16` 格，单箱四周内缩 `1/16` 格；大箱子外轮廓连续，中央接缝没有碰撞或射线空隙，且不会像完整方块一样遮住相邻表面
- 箱盖使用约 0.5 秒的开合动画；大箱子任一半上方有不透明实体方块时都无法打开，玻璃和树叶不会阻挡开箱
- 箱子只轻微衰减天空光和方块光，不再作为完整不透光方块处理
- 斧是箱子的有效采掘工具；徒手也能完整采集，破坏后掉落 1 个箱子

### 火把与光照

- 火把提供 14 级暖色局部光，可由下方实体方块支撑在地面，也可由四个水平相邻实体方块支撑在墙面
- 支撑被移除后，只有在下方和四个水平相邻方向都失去支撑的火把才会脱落；生存模式生成 1 个火把掉落物，创造模式直接移除
- 敌对生物生成会同时检查“实际天空光 × 当前昼夜亮度”和方块光，因此白天的暗洞仍可能生成敌对生物，火把附近则会因方块光照受到抑制

### 攻击

- 每次攻击后蓄力条会自动恢复；蓄力越完整，伤害倍率由 20% 提升到 100%
- 空手满蓄力约 0.25 秒，剑约 0.625 秒，镐约 0.83 秒，锹 1 秒，斧约 1.11 到 1.25 秒
- 挖掘方块会保留战斗蓄力，对空挥击会清零蓄力
- 实体受到有效攻击后有 0.5 秒受伤无敌帧；同等或更弱命中不伤害、不耗耐久，更强命中只补伤害差值并消耗一次耐久
- 剑攻击消耗 1 点耐久，镐、斧、锹攻击消耗 2 点耐久

### 护甲

皮革甲、铁甲和钻石甲只能放入对应的头、胸、腿、脚装备槽。皮革甲整套提供 7 点防御，
铁甲整套提供 15 点防御，钻石甲整套提供 20 点防御和 8 点韧性：

| 部位 | 防御 | 韧性 | 最大耐久 |
| --- | ---: | ---: | ---: |
| 皮革帽子 | 1 | 0 | 55 |
| 皮革上衣 | 3 | 0 | 80 |
| 皮革裤子 | 2 | 0 | 75 |
| 皮革靴子 | 1 | 0 | 65 |
| 铁头盔 | 2 | 0 | 165 |
| 铁胸甲 | 6 | 0 | 240 |
| 铁护腿 | 5 | 0 | 225 |
| 铁靴子 | 2 | 0 | 195 |
| 钻石头盔 | 3 | 2 | 363 |
| 钻石胸甲 | 8 | 2 | 528 |
| 钻石护腿 | 6 | 2 | 495 |
| 钻石靴子 | 3 | 2 | 429 |

护甲当前用于抵挡敌对生物攻击，减伤会随该次伤害动态计算，不是固定百分比。当前公式为
`有效护甲 = min(20, max(防御 / 5, 防御 - 伤害 / (2 + 韧性 / 4)))`，最终伤害为
`原伤害 × (1 - 有效护甲 / 25)`；例如整套铁甲会把 10 点伤害降为 6 点。
每次抵挡生物攻击时，所有已装备部件都会损失 `max(1, floor(原伤害 / 4))` 点耐久，归零后损坏。

### 牛与皮革

- 被动生物自然生成权重为羊 40%、猪约 33.3%、牛约 26.7%，三者共享最多 8 只的上限
- 牛拥有 10 点生命，死亡掉落 1 到 3 个生牛肉，以及 0 到 2 个皮革
- 生牛肉恢复 3 点饥饿和 1.8 饱和度；熔炉烹饪后的牛排恢复 8 点饥饿和 12.8 饱和度
- 皮革可按标准头、胸、腿、脚配方在 3x3 工作台中制作四件皮革甲

### 苦力怕、爆炸与火药

- 苦力怕拥有 20 点生命，与僵尸共享敌对生物上限；普通击杀掉落 0 到 2 个火药，自爆不会生成自身掉落
- 苦力怕在玩家 3 格内且视线畅通时开始 1.5 秒引信，停止移动并逐渐膨胀闪烁；玩家离开 7 格、失去视线或切换到创造模式后，引信会回退并取消
- 爆炸使用确定性的 16x16x16 立方体边界射线、方块爆炸抗性和非球形坑洞；水与基岩不会被苦力怕爆炸摧毁
- 玩家与生物伤害根据距离和爆炸前的实际遮挡暴露度计算，并同时产生护甲减伤、耐久损耗与击退
- 被炸毁方块按爆炸衰减概率生成掉落；箱子和熔炉会通过正常移除流程释放内部物品，不会留下失效容器状态

世界种子、方块修改、玩家位置、创造快捷栏、生存状态、背包、合成格、鼠标物品、
护甲装备、世界掉落物、熔炉状态、设置和昼夜时间会保存在浏览器本地。
旧版创造存档可继续加载。更换浏览器、清除站点数据或使用不同地址打开游戏时，不会自动迁移存档。
